# Windows 版本

此目录为 Windows x64 助手，沿用 macOS 版本的五章节协议、物品白名单和游戏补丁规则；macOS 原生应用仍从 `zm5-only` 构建。Windows 客户端接入及实际战斗效果需要在所选兼容客户端上验证，不能根据助手能打开就认定 Flash 和所有游戏功能都已兼容。

## 使用

1. 将 `zaomeng-xiyou-v<版本>-windows-x64.zip` **完整解压**到可写目录，双击 `ZMXYHelper.exe`。不要在压缩包内直接运行，不要只复制 EXE。助手无需另装 Node.js、Python、Swift 或 Xcode。
2. 点击「官方下载客户端 ↗」，自行从官方页面安装兼容的 **Windows Electron/PepperFlash 桌面客户端**，再在助手中点击「选择客户端」选择它的 EXE。普通浏览器、手游、只有 `app.asar` 的客户端或任意一个 EXE 均不能保证兼容。需要客户端包含可写的 `resources/app/main.js`，且保留旧 Electron 的 Flash 支持。
3. 在游戏里保存并完全退出客户端，选择造梦1～5，再点击「接入并打开游戏」。造梦1～4首次接入需要对应版本的官方原始 SWF，可用「官方游戏文件」下载；造梦5检查官方最新入口，结构验证通过后在本机生成并缓存补丁。
4. 进入对应章节后设置倍率并应用。各章节设置分别维护。物品操作仅点击时发送一次，收到成功回执后自行在游戏里保存；结果未知时先检查背包，避免重复操作。
5. 需要撤销接入时，保存并完全退出游戏，点击「恢复客户端」。该操作恢复接入前备份的客户端入口和配置。保留客户端的接入备份，直到确认不再需要恢复。

助手自身使用现代 Electron 显示界面；运行 Flash 游戏的是用户自行安装的旧版兼容客户端。发布包不含第三方客户端、Flash 插件或完整游戏 SWF。客户端目录需要写入权限；可将兼容客户端安装到本人可写的目录。此版本未进行 Windows 代码签名，系统可能显示未知发布者提示。

官方来源：[淘米官方客户端下载页](https://webres.61.com/common/flash/common_micro.html?game=mole)、[4399 造梦西游入口](https://www.4399.com/flash/zmhj.htm)。游戏文件只在用户执行下载或接入操作时获取，校验失败或结构不兼容会停止。

## 游戏显示模式

助手提供两种游戏显示模式，选择会保存在本机：

- **原生像素**（默认）：按屏幕原生像素显示游戏，优先保持画面清晰。在高 DPI 屏幕上，窗口和文字会较小。
- **跟随系统缩放**：沿用 Windows 的显示缩放，窗口和文字较大；旧版 Flash 客户端在 150% 等缩放比例下可能出现模糊。

更改模式后，先在游戏中保存并完全退出客户端，再点击「接入并打开游戏」，新模式在本次启动时生效。可根据屏幕大小和阅读需要选择。

## 关闭游戏

关闭游戏前请自行保存。v5.10.1 修复了兼容 Windows 客户端关闭窗口时可能卡住的问题：助手先释放该窗口的接入连接，再走正常关闭流程，不强制结束进程。

若游戏页面阻止关闭，会显示确认框，默认选择「返回游戏」；确认已保存后可选择「已保存，关闭游戏」。返回游戏后会恢复原章节的接入，不重新加载游戏，已发送的物品操作不会自动重试。

## 开发与构建

在 Windows x64 安装 Node.js 22.12+ 与 Git，然后在项目根目录执行：

```powershell
cd windows
npm ci
npm test
npm start
npm run build
```

`npm ci` 会安装锁定的 JavaScript 依赖并下载 Electron 运行时，需要能访问 npm 和 Electron 的官方发布源。如果运行时下载中断，执行 `node node_modules/electron/install.js` 后重试。构建命令不下载或运行第三方游戏客户端，也不需要官方 SWF。

构建结果位于仓库根目录 `dist`：

- `zaomeng-xiyou-v<版本>-windows-x64/ZMXYHelper.exe`：可直接打开的完整目录。
- `zaomeng-xiyou-v<版本>-windows-x64.zip`：可分发的压缩包。
- `zaomeng-xiyou-v<版本>-windows-x64.sha256`：压缩包 SHA-256 校验值。

软件版本以 `zm5-only/Info.plist` 为来源；打包时写入 Windows 的运行时版本信息。`build.ps1` 只复制明确列出的自写助手文件、规则和 `lzma` 运行时依赖，不复制开发工作区、下载缓存或用户客户端。再次构建仅覆盖有本脚本标记的同版本产物目录。

CI 在 Windows 上运行共享逻辑及 Windows 测试、构建无 SWF 的完整包，并上传构建产物。版本 Tag 的正式 Release 需要 macOS 和 Windows 检查均通过；本机运行、客户端接入和游戏内效果的验收范围应分别记录，不将 CI 通过等同于实战验收。
